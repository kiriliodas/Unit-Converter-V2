## What's new

- Added optional **Material You** dynamic color in **Settings > Appearance** on Android 12 or later.
- When enabled, the app's surfaces and primary actions adapt to colors generated from your wallpaper and system palette.
- The original monochrome appearance remains the default and is still used when Material You is disabled or unavailable.

## Updating from v2.1.0

Open Unit Converter v2.1.0, go to **Settings > Updates**, check for updates, then download and install this release from inside the app. Android still asks for confirmation before installation.

## Compatibility

- Android 8.0 (API 26) or later
- Material You dynamic color requires Android 12 (API 31) or later
- Application ID: `com.kirilliodas.unitconverter`
- Version: `2.1.1` (versionCode `3`)

Download `Unit-Converter-V2.1.1.apk`. The matching `Unit-Converter-V2.1.1.apk.sha256` file is provided for integrity verification.
