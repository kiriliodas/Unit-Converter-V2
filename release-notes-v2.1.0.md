## What's new

- Added a native in-app update system for official GitHub releases.
- Added an **Updates** section in Settings for manual update checks.
- Update downloads show progress and can be cancelled.
- Downloaded APKs are checked against the published SHA-256 file when available and validated for package identity, version, and signing identity before Android's installer is opened.
- Installation always remains under the user's control through Android's standard installer.

## Important for v2.0.0 users

Version 2.0.0 does not contain the updater, so install v2.1.0 manually from this release once. Future stable releases can then be discovered from inside the app.

## Compatibility

- Android 8.0 (API 26) or later
- Application ID: `com.kirilliodas.unitconverter`
- Version: `2.1.0` (versionCode `2`)

Download `Unit-Converter-V2.1.0.apk`. The matching `Unit-Converter-V2.1.0.apk.sha256` file is provided for integrity verification.
